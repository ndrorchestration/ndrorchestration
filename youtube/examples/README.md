# Reproducible educational examples

When an episode demonstrates a prompt, evaluation rubric, program, or workflow, add a small, reproducible example here. Each example should record:

- The episode URL and timestamp
- Learning objective and prerequisites
- Input, steps, and expected output
- Versions, dates, and environment where relevant
- Known limitations and safety or privacy boundaries

Examples must distinguish illustrative/synthetic outputs from measured evidence. Links to existing engineering repositories are preferable to duplicating maintained code.
