# Andrew “Ender” Hensel

I design and test AI workflows. I’m interested in what happens when an agent gets an instruction wrong, how we can tell, and who gets to decide what it does next.

I’m open to remote work in AI evaluation, prompt engineering and AI training. [Connect on LinkedIn](https://www.linkedin.com/in/andrewhensel).

## Five flagship projects

### 01 — [Agentic Governance Orchestrator (AGO)](https://github.com/ndrorchestration/DGAF-Framework)

Proposed successor identity for my experimental agentic governance research (currently hosted in the DGAF-Framework repository). It investigates evidence-bound authorization, provenance and accountable orchestration. A conventional policy checker matched the earlier decision model across 112,200 enumerated synthetic states. The incremental value of the broader assurance lifecycle remains an open research question; independent validation and high-assurance authorization are not established. The formal identity cutover is pending.

### 02 — [Agent Control Plane (ACP)](https://github.com/ndrorchestration/agent-control-plane)

A Python kernel that dispatches tasks, checks permissions and records what ran. Its local tests cover what happens when an agent requests an unknown capability or a task is cancelled.

### 03 — [To Sail the Starry Sky](https://github.com/ndrorchestration/ToSailtheStarrySky-jrpg)

A solarpunk role-playing game in development in Unreal Engine. Its opening follows Ender, a mechanic hired to repair an airship. The public C++ project shows how quest order, combat turns and save checks fit together.

### 04 — [ResumeApex Career Assistance Evaluation Suite](https://github.com/ndrorchestration/resumeapex-eval)

A Python harness for evaluating AI assistance with résumés and career tasks. You can run it twice on examples with known answers and compare the reports byte for byte.

### 05 — [Collabration](https://github.com/ndrorchestration/Collabration)

An alpha social app that makes AI contributions visible. Its Content Passports trace revisions so readers can see what changed, who approved it and how to request a correction.
