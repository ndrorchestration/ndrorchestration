## Rank colouring

Colour a subset red when its cardinality lies in

```text
{0,2,3,6,8}
```

and blue when its cardinality lies in

```text
{1,4,5,7}.
```

The exact closure enumerators included here exhaust all union-closed families contained in each colour class whose size is less than 9. They find no extension to a union-closed family of size at least 9.

The same counts are reproduced independently by the C++ and Python implementations.

```text

blue: {1,15,23,27,29,30,31,127}
```

(Subsets are encoded as 8-bit integers.) Thus this particular colouring has monochromatic union-closed maximum exactly 8, proving `F(8) <= 8`.

## Why the closure enumeration is exhaustive

If `C` is already union-closed and a new set `x` is added, the union-closure generated by `C union {x}` is exactly

```text
C union {x} union {x union y : y in C}.
```

The verifier begins with the empty family and explores every distinct closure obtainable by repeatedly adding an allowed-colour set, retaining every state of size below 9. Every finite union-closed family can be generated by successively adding its own members; each intermediate generated closure stays inside that family. Therefore, if a union-closed family of size at least 9 existed in the colour class, some explored extension would reach size at least 9.
